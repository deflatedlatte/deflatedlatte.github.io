ServerHold: DNS의 또 다른 함정

돈을 내고 도메인 네임을 구매해도, 레지스트리 오퍼레이터 마음대로 DNS에서 없애버릴 수 있습니다.

작년 초 쯤 개인적으로 사용하기 위해 deflatedlatte.site라는 도메인 네임을 구매한 적이 있다. 어느 때처럼 등록 대행자를 통해서 권리를 얻고, 네임 서버를 호스팅 업체 것으로 바꾸고, 서버 설정을 바꾸고... 큰 문제 없이 서버에 접속되는 것까지만 확인하고 크게 신경 쓰지 않았다.

며칠이 지나서, 서버를 사용하려고 해당 도메인으로 접속을 시도했다. 그런데...

도메인 검색 자체가 안된다는 에러가 떴다.

처음 겪는 상황에 당황한 나

다른 클라이언트로 접속 시도도 해보고, dig로 직접 질의도 해보고, 혹시 내가 쓰고 있는 DNS의 문제인가 싶어서 다른 DNS도 써보고, 호스팅 업체가 실수를 했나 싶어서 네임 서버 설정까지 등록 대행자 기본값으로 원복해봤지만 아무런 소용이 없었다.

결국 도메인 등록 대행 업체에 전화를 걸어서 물어보기로 했다. 대충 상황 설명을 마치고 나니 돌아오는 대답은 "지금 네임 서버 설정을 변경한지 얼마 되지 않았으니, 24시간을 채우고 다시 확인해보라"라는 말이었다. 솔직히 말해서 그런다고 될 것 같지는 않았지만, 일단 다른 방도도 없으니 좀 더 기다려보기로 했다.

24시간을 채우고 다시 시도해보니, 여전히 증상은 똑같았다.

이 시점에서 등록 대행자에 다시 물어보는 것은 반쯤 포기하고 (일단 다시 전화를 걸어서 대기열을 기다리는 게 귀찮았다), 도메인 등록과 관련된 정보를 찾아보기 시작했다. 그러던 중 우연히 whois 정보를 확인해보았는데, 

$ whois deflatedlatte.site
Domain Name: DEFLATEDLATTE.SITE
Registry Domain ID: ...
Registrar WHOIS Server: ...
Registrar URL: ...
Updated Date: 2025-03-27T13:58:02.0Z
Creation Date: 2025-03-16T08:07:03.0Z
Registry Expiry Date: 2026-03-16T23:59:59.0Z
Registrar: ...
Registrar IANA ID: ...
Domain Status: serverHold https://icann.org/epp#serverHold
Domain Status: serverTransferProhibited https://icann.org/epp#serverTransferProhibited
Domain Status: clientRenewProhibited https://icann.org/epp#clientRenewProhibited
Domain Status: clientTransferProhibited https://icann.org/epp#clientTransferProhibited
Domain Status: clientUpdateProhibited https://icann.org/epp#clientUpdateProhibited
Domain Status: clientDeleteProhibited https://icann.org/epp#clientDeleteProhibited

...생략...

나에겐 생소한 serverHold라는 상태가 추가되어 있었다. 고맙게도, 이게 어떤 의미인지는 옆에 https://icann.org/epp#serverHold를 보라고 적혀 있다.

This status code is set by your domain's Registry Operator. Your domain is not activated in the DNS.

그러니까 등록 대행자가 아니라 레지스트리 오퍼레이터가 설정한 상태라는 뜻이다. 등록 대행자는 말 그대로 도메인 등록만 대행해주는 것이지, 실제 TLD 네임 서버 운영은 레지스트리 오퍼레이터가 맡는 형태가 된다.

이쯤 되면 슬슬 불안해지기 시작하는데, 등록 대행을 거쳐 오퍼레이터에게 연락해야 하는 상황이 올까봐 무서웠다. 위에서 잠깐 말했지만, 등록 대행 업체에 전화 상담을 했을 때 문제 해결에 직접적인 도움을 받기 쉽지 않을 거라는 느낌을 받았다. 아마도 전화 상담원과 매뉴얼대로 한참 헤매다가 간신히 서포트 티켓을 받을 거고, 그 뒤에도 몇 주에 걸쳐 대행 업체를 끼고 오퍼레이터와 씨름하는 모습이 상상됐다.

레지스트리 오퍼레이터를 찾아서

일단 .site 도메인의 오퍼레이터가 누구인지 확인해보기로 했다. 

$ whois site
% IANA WHOIS server
% for more information on IANA, visit http://www.iana.org
% This query returned 1 object

domain:       SITE

organisation: Radix Technologies Inc. SEZC
address:      ...
address:      ...
address:      ...

...중략...

status:       ACTIVE
remarks:      Registration information: https://radix.website/

...생략...

오, 뭔가 웹사이트가 있다. 이곳을 뒤져보니,

정지 해제 요청 양식이 있다. 여기에 내 도메인을 입력해봤다.

이유는 모르겠지만 deflatedlatte.site라는 도메인이 abusive한 것으로 판단되어 정지되었다고 한다; 어쨌든 정지 해제 요청을 보내고 나니 얼마 지나지 않아 다음과 같은 회신을 받을 수 있었다.

그러니까 도메인 이름이 자동 생성된 패턴으로 판단되어서 정지되었다는 얘기다. 내 닉네임이 너무 3류여서 그런가보다;;

별 수 없으니 다시 해당 이메일로 억울함을 호소하는 답장을 보냈다.

딱 하루가 지나서 다음과 같이 ServerHold를 해제했다는 답장을 받을 수 있었다.

나만 그런건가?

나와 비슷한 사례가 분명히 있을 것 같아서, 이곳저곳을 찾아보니 이런 글을 발견할 수 있었다.

  • https://news.ycombinator.com/item?id=40195410
  • https://pinggy.io/blog/domain_outage_incident_april_2024/

해당 도메인을 제공하는 Radix Technologies의 공식 X 계정을 검색해보니 꽤 많은 사람들이 도메인이 정지되었다고 호소하는 글을 볼 수 있었다.

결론

나는 정지 해제를 받은 이후로 1년간 별다른 이슈 없이 도메인을 잘 사용했지만, 처음 겪어보는 이슈인만큼 적잖게 당황할 수 밖에 없었다.

일단 도메인 정지가 되었음에도 내가 문의하기 전까지는 관련해서 연락 받은 것이 하나도 없었다. 대행 업체에서 도메인 이름을 구매할 때 익명으로 등록해서 그런걸까? 처음부터 안내 이메일이 발송되긴 했던건지, 아니면 대행 업체를 거쳐오다가 메일이 누락된 건지는 잘 모르겠다.

어쨌든 이 도메인은 자료 제공용으로 급하게 등록했던 것인데, 막상 중요한 순간에 동작을 안하니 원래 목적으로 사용조차 할 수 없었다. 만약 production 서비스 용도로 사용하는 도메인이 이와 같이 통보도 없이 정지된다면 꽤나 골머리를 앓을 수 밖에 없을 것 같다.

실제 서비스를 제공하는 용도로 도메인 네임을 구매한다면, .com이나 .net과 같이 어느 정도 신뢰성 있는 TLD를 사용하거나, 정 안되면 도메인을 미리 구매해두고 몇 달 정도 묵혀두며 서비스 오픈 전에 검증해보는 것이 좋을 것 같다. 물론 그렇다고 해도 오퍼레이터가 (실수든 고의든) 도메인 네임을 내려버릴 수 있다는 사실은 변하지 않지만...
